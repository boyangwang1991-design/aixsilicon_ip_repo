## 20. 附录

### 20.1 设计 ID 命名规范

```text
HLD.MOD.L1.X2P.<MODULE>     # 一级架构模块 ID
HLD.FLOW.X2P.<FLOW>         # 数据流/控制流 ID
HLD.DOM.X2P.<DOMAIN>        # 时钟/复位/电源域 ID
HLD.IF.EXT.X2P.<INTERFACE>  # 外部接口 ID
```

### 20.2 LRS 到 HLD 转换规则

| LRS 类型 | HLD 设计输出 |
|---|---|
| 功能需求 | 功能流程、状态机、子模块职责 |
| 接口需求 | 接口表、协议响应 |
| 性能需求 | buffer、pipeline、仲裁、latency budget |
| 约束需求 | 参数合法性、不支持场景 |
