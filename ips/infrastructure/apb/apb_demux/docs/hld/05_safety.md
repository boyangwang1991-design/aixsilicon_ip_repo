## 1. 功能安全 / Safety

**N/A - 本 IP 无 ISO 26262 功能安全目标。**

APB Demux 为地址路由互联 IP，不承担安全相关功能，无 ECC/Parity、错误注入或
安全机制。SoC 级安全监控（如 APB Timeout Monitor）由系统级实现，不在本 IP
范围内。
