## 逐需求验收范围

- `LRS.INTF.APB_SECURE_DEMUX.APB.001`：非法访问从 SETUP 开始所有下游 PSEL 必须为 0，不得引发读清除、FIFO 弹出、写启动或其他副作用。
- `LRS.INTF.APB_SECURE_DEMUX.APB.002`：所有本地拒绝在第一个上游 ACCESS 周期响应 PREADY=1、PSLVERR=1、PRDATA=0；包括 REGISTER_MODE=1。
- `LRS.INTF.APB_SECURE_DEMUX.APB.003`：成功 CSR 访问在第一个 ACCESS 周期 PREADY=1、PSLVERR=0；CSR 副作用仅在完成边沿发生一次。
- `LRS.INTF.APB_SECURE_DEMUX.APB.004`：正常外设访问透传下游完成响应；下游 PSLVERR=1 时上游仍返回该错误，下游 PRDATA 原样透传，不按权限拒绝处理。
- `LRS.INTF.APB_SECURE_DEMUX.APB.00501`：无有效 ACCESS 时上游 PSLVERR=0；PRDATA=0，PREADY=1。
- `LRS.INTF.APB_SECURE_DEMUX.APB.00502`：复位期间按第 13 节强制值。
- `LRS.INTF.APB_SECURE_DEMUX.APB.00601`：所有周期 m_psel 满足 one-hot-or-zero。
- `LRS.INTF.APB_SECURE_DEMUX.APB.00602`：未选端口 m_penable=0，选中端口遵守完整 SETUP/ACCESS 时序。
- `LRS.INTF.APB_SECURE_DEMUX.APB.007`：OUTPUT_ISOLATION_EN=1 时，未选端口 PADDR/PWDATA/PSTRB/PWRITE/PPROT/MASTERID 均置零；=0 时可以广播当前请求，但 PSEL/PENABLE/身份有效不得广播。
- `LRS.INTF.APB_SECURE_DEMUX.APB.00801`：支持 PSEL 连续保持的背靠背事务、读写交替、切换目标、CSR 与外设交替。
- `LRS.INTF.APB_SECURE_DEMUX.APB.00802`：每个新 SETUP 必须重新译码和判权。
- `LRS.INTF.APB_SECURE_DEMUX.APB.009`：不存在 posted write 或提前成功响应；外设事务完成前不得释放上游。
- `LRS.INTF.APB_SECURE_DEMUX.APB.01001`：不支持主动取消已发出的下游事务。
- `LRS.INTF.APB_SECURE_DEMUX.APB.01002`：等待告警、DFX 授权撤销或新完整性故障均不得中途撤销 PSEL。
- `LRS.PERF.APB_SECURE_DEMUX.TIM.001`：SETUP 的组合权限路径须纳入 STA，包括地址/身份/PPROT 到下游 PSEL 的路径；不承诺物理意义的无毛刺安全隔离。
- `LRS.PERF.APB_SECURE_DEMUX.TIM.002`：零等待下游比直接模式多一个上游等待周期；该模式寄存请求路径，不保证切断下游响应到上游响应的组合路径。
- `LRS.PERF.APB_SECURE_DEMUX.TIM.003`：本地 CSR 和权限拒绝不走下游转发状态机，仍在第一个 ACCESS 周期完成。
- `LRS.PERF.APB_SECURE_DEMUX.TIM.004`：寄存模式必须锁存 PADDR/PWDATA/PSTRB/PWRITE/PPROT/MASTERID 和版本，禁止仅锁存地址却使用下一笔数据。
- `LRS.PERF.APB_SECURE_DEMUX.MODES.013`：直接模式的合法零等待外设访问不得增加上游等待；寄存模式恰增加一个上游等待周期并完整保留请求；两模式的本地 CSR 和拒绝均在第一个 ACCESS 完成。
