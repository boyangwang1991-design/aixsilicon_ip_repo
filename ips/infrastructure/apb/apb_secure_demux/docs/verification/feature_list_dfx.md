## 逐需求验收范围

- `LRS.DFX.APB_SECURE_DEMUX.DFX.00101`：DFX 控制只在 DFX_EN=1、管理授权和 dfx_authorized_i=1 时允许。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.00102`：DFX 硬件授权不能由本 IP 的 CSR 自行产生。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.00201`：授权变低时，下一时钟边沿解除所有未触发注入武装；观测输出受授权门控。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.00202`：已经完成的事件和计数不自动清除。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.003`：SUCCESS_COUNT 只统计下游 PREADY=1 且 PSLVERR=0 的完成事务；DENY_COUNT 只统计唯一命中该端口的拒绝；SLVERR_COUNT 统计下游错误。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.004`：所有 32 bit 计数饱和不回绕；同周期清除和递增时先清零再累加本周期事件。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.00501`：WAIT_TOTAL 只计算下游 PSEL && PENABLE && !PREADY 周期，不包括寄存模式额外 SETUP 周期。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.00502`：WAIT_MAX 在完成时更新；未完成事务通过硬件阈值输出观测。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.006`：WAIT_THRESHOLD=0 禁用告警；T>0 时，在单笔第 T 个等待周期边沿触发一次 WAIT_EXCEEDED 并置 WAIT_HIT；同笔不重复触发，新事务重新计数。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.00701`：busy_o 表示有外设事务正在 SETUP/ACCESS；active_port_valid_o 随有效目标，active_port_o 无效时为 0。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.00702`：仅诊断信号，不作为授权凭据。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.008`：wait_threshold_o 表示授权条件下的粘滞 WAIT_HIT，清除由 DFX_CLEAR[0]；不会终止下游事务。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.00901`：INJECT_TARGET 写入时检查端口和主体范围；武装时锁存目标。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.00902`：武装期间改目标或再次武装返回 CMD_INVALID，须先解除。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.01001`：强制拒绝为一次性；匹配 MASTERID/端口、原本合法的下一笔事务在 SETUP 被拒绝，产生 DFX_FORCED_DENY，完成时计拒绝、bit0 与 bit8。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.01002`：自然非法事务不消耗武装。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.01101`：完整性故障注入为一次性；匹配的下一笔原本合法事务在 SETUP 阻断，在 SETUP 结束边沿置全局 FATAL，产生带 TEST 的 INTEGRITY_DETECTED；该笔完成再产生 INTEGRITY_BLOCK，标记 TEST。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.01102`：后续访问按普通 FATAL 拒绝。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.01103`：该模式需 POLICY_PARITY_EN=1，否则命令错误。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.012`：DFX 完整性注入测试“检测结果至阻断/告警”路径，不翻转实际权限存储位，不能代替验证环境的真实 parity 位故障注入测试。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.013`：合成日志命令在完成边沿产生 DFX_SYNTHETIC，TEST=1、REQUEST_VALID=0；不访问任何外设，不增加访问拒绝计数。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.01401`：无软件安全 bypass。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.01402`：scan/test 信号的工艺接入由 DFT 架构约束，功能模式下不得改变权限；不得以 DFX_EN 为条件绕过正常访问检查。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.01501`：单 APB 输入被下游等待占用时，软件无法通过同口读取 DFX CSR；这是接口边界。
- `LRS.DFX.APB_SECURE_DEMUX.DFX.01502`：系统若需要独立救援访问，应在外围提供独立观测/复位通路，不能假定本 IP 可取消 APB。
