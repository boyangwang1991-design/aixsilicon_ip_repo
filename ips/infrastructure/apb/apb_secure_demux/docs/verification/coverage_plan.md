# 覆盖与关闭标准

功能义务按后续分册列出的强制bins验收，每一bin必须命中或有单独评审豁免；未列出的随机分布不能替代这些义务。代码line/branch/condition/toggle/FSM状态和转移分别报告分母、覆盖数、范围与数据库身份。未覆盖代码逐项解释，不把generated CSR从总DUT统计中悄然移除。

static feature的bins由实际证据checker的逐项结果提供，不能虚构成UVM covergroup命中。覆盖库仅合并相同elaboration配置，不跨典型/最大或裁剪配置混分母。每个配置单列必需功能bins；不适用项明确列出参数条件，不能把“没有运行”写成不可达。

小配置可以穷尽事件组合和锁/提交选择，最大配置需验证完整主体域与位宽/资源边界。形式性质记录非空激活/cover witness，不能仅凭无assert失败判断充分。所有排除/waiver在提出后说明具体路径、条件、证明和批准，当前没有预先批准项。
