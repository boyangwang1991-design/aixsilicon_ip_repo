## 逐需求验收范围

- `LRS.SEC.APB_SECURE_DEMUX.ACL.00101`：每个端口、每个主体维护独立 8 bit PERM。
- `LRS.SEC.APB_SECURE_DEMUX.ACL.00102`：1 允许，0 拒绝；读写与四种属性均可独立配置。
- `LRS.SEC.APB_SECURE_DEMUX.ACL.00201`：Secure、特权和管理主体均无隐含外设访问豁免。
- `LRS.SEC.APB_SECURE_DEMUX.ACL.00202`：管理身份访问外设时仍查端口权限表。
- `LRS.SEC.APB_SECURE_DEMUX.ACL.00301`：PORT_CFG[0]=ENABLE；[1]=INSTR_ALLOW。
- `LRS.SEC.APB_SECURE_DEMUX.ACL.00302`：其余位保留为零。
- `LRS.SEC.APB_SECURE_DEMUX.ACL.00401`：数据访问检查相应读写位。
- `LRS.SEC.APB_SECURE_DEMUX.ACL.00402`：指令读还必须 INSTR_ALLOW=1；指令写一律拒绝。
- `LRS.SEC.APB_SECURE_DEMUX.ACL.005`：身份无效或越界必须拒绝，不映射为主体 0；PSTRB=0 仍执行正常写权限检查。
- `LRS.SEC.APB_SECURE_DEMUX.ACL.006`：判权结果与目标在事务边界锁定，等待期间不得重新按新策略改变当前事务。
- `LRS.SEC.APB_SECURE_DEMUX.ACL.007`：默认 RESET_PORT_CFG 和 RESET_PERM 全零；硬件启动权限只能通过显式参数定义，active 与 shadow 复位内容一致。
- `LRS.SEC.APB_SECURE_DEMUX.ATTRIBUTES.004`：PPROT 的低两位以 {Non-secure, privileged} 编码四类属性，读权限分别使用 PERM 低四位，写权限使用高四位；指令属性不改变主体身份。
