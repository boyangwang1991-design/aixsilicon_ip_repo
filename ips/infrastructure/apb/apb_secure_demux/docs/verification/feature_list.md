## 逐需求验收范围

- `LRS.CFG.APB_SECURE_DEMUX.PAR.001`：CSR_SIZE 固定按 `0x1000 + NUM_PORTS × 0x400` 字节推导；所有区间使用扩展位宽计算结束地址，不允许截断或回绕。
- `LRS.CFG.APB_SECURE_DEMUX.PAR.002`：任一 PORT 区间、本地 CSR 区间越出地址宽度，存在重叠、大小为零或未按 4 字节对齐，必须在 elaboration/配置检查阶段失败。
- `LRS.CFG.APB_SECURE_DEMUX.PAR.00301`：端口支持任意符合上述约束的大小，无须是 2 的幂。
- `LRS.CFG.APB_SECURE_DEMUX.PAR.00302`：结束地址为 BASE+SIZE-1。
- `LRS.CFG.APB_SECURE_DEMUX.PAR.004`：1 个端口、1 个主体、FIFO 深度 0/1、非 2 的幂规模必须可编译且行为正确；内部索引宽度不得出现零宽向量。
- `LRS.CFG.APB_SECURE_DEMUX.PAR.005`：MASTERID 必须先检查完整输入值是否小于 NUM_MASTERS，再索引权限表；禁止截断高位导致身份混叠。
- `LRS.CFG.APB_SECURE_DEMUX.PAR.006`：CAPABILITY 和地址只读镜像必须反映实际 elaboration 参数。
- `LRS.CFG.APB_SECURE_DEMUX.PARAMETERS.001`：IP 应支持 NUM_PORTS=1..32、ADDR_WIDTH=16..32、DATA_WIDTH=32、MASTER_ID_WIDTH=1..16、NUM_MASTERS=1..64，且主体数量不超过身份编码空间。
- `LRS.CFG.APB_SECURE_DEMUX.OPTIONS.002`：REGISTER_MODE、OUTPUT_ISOLATION_EN、POLICY_PARITY_EN、DFX_EN、PUBLIC_ID_EN 均为独立布尔参数；EVENT_FIFO_DEPTH 为 0..32。复位权限和端口使能默认全零；管理掩码非零且由集成提供。
