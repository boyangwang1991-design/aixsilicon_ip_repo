## CDC / RDC 与低功耗

没有 IP 内部 CDC/RDC 跨域数据路径，派生 cdc_paths 为空表示不适用，不表示外部同步已验证。
异步授权必须在集成层同步，IRQ/alert 跨域由接收端同步。复位释放须由系统保证所有功能逻辑同步退出。
N/A：不设独立电源切换、retention 或本地 clock gating。外部停钟只允许无进行中事务且配置保持。

## PPA 与资源

权限数据容量为 2×NUM_PORTS×NUM_MASTERS×8 bit，另有 CFG、校验、锁、快照和 EVENT_FIFO_DEPTH×256 bit 日志。
典型权限数据 2048 bit，最大权限数据 32768 bit；这些是结构预算，不是综合面积或功耗结果。
直接模式地址/身份/属性→PSEL，以及完整性检测→PSEL 必须纳入 STA。寄存模式不保证隔断响应组合路径。
实际工艺、角、周期与 IO 预算仍待集成，后续必须报告典型/最大和两模式各自的综合结果。
