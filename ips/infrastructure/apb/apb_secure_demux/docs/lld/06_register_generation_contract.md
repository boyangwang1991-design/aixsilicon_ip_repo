# 寄存器结构生成与配置绑定

本IP为参数化SystemVerilog，CSR结构需要与实例配置一致。采用参数化SystemRDL源描述端口/主体数组、功能存在性及复位镜像；构建时按受校验的实例参数elaborate，使用固定槽位步长，不能按裁剪重新排址。该步骤只生成寄存器结构视图，不用Python生成访问控制/FSM/队列行为。

SystemRDL exporter 的具体参数能力须在02阶段验证：NUM_PORTS/NUM_MASTERS控制数组规模，DFX_EN及FIFO是否实现决定存在性；RESET_PORT_CFG/RESET_PERM及只读参数镜像必须反映该实例。若数组参数表达能力不足，应由实例参数确定性展开RDL结构，并将参数源、展开器及RDL哈希绑定；禁止以全零RAL复位值代表非零启动权限配置。

发布的每个CSR生成集绑定参数实例摘要：端口/主体规模、地址宽度、所有裁剪位、FIFO深度、地址/大小、管理掩码、启动策略和模式。顶层elaboration参数与生成配置不一致时构建失败，不能容忍CSR槽位与功能状态阵列维度失配。公共参数覆盖矩阵每种配置分别生成并编译，不只改变顶层参数复用旧CSR binary。

RDL保持单一结构来源。APB wrapper 如需识别公开窗口、DFX授权域或结构错误种类，应从同一RDL节点及访问策略注解导出辅助结构元数据，不能另写独立offset/bit表。动态锁、命令是否合法及完整性属于行为owner，最终状态变化由接受脉冲门控。状态由external reg接口接入，生成模块承担结构解码、访问属性及错误。实际exporter接口与时序确认是02阶段的必做检查。

工具生成包需记录PeakRDL及各exporter版本、完整命令、输入/输出哈希、原生生成包先于模块的编译结果。RTL、RAL、C header、HTML和IP-XACT必须来自同次结构输入。G2只在行为冻结与生成证据均满足后通过。
