## 两种 APB 模式

IDLE 中合法 direct SETUP 组合驱动唯一目标 PSEL，PENABLE=0。SETUP 末沿上下文锁存后 ACCESS 用寄存请求驱动目标，PENABLE=1。register 模式 IDLE 下游全不选，REG_SETUP 才置 PSEL，PENABLE=0；随后进入 ACCESS。两模式合法下游零等待分别增加零拍/一拍上游等待。

ACCESS 完成完全由捕获端口的 m_pready 决定。m_pslverr/m_prdata 原样返回，包括下游错误数据。LOCAL 在第一个上游 ACCESS 返回完成；拒绝 data=0/error=1，成功 CSR error=0。无有效 ACCESS 或复位，上游 ready/error/data 全零；REG_SETUP ready=0。

选择和 identity valid 对所有未选端口始终为零。OUTPUT_ISOLATION_EN=1 时未选端口地址、控制负载、数据、属性和身份清零；为0时可广播当前请求负载，但 PSEL/PENABLE/master_valid 仍仅唯一选中端口有效。空闲可广播上游负载，无权限含义。

## 保持及异常

等待时使用同一上下文，不响应新地址、策略提交、授权撤销或 FATAL 而更换目标/撤销 PSEL。WAIT_THRESHOLD 只产生事件，不强制完成。不会在下游完成前提交外设成功统计。复位异步门控选择为零；复位前副作用由系统协调。
