## 授权、武装与一次性触发

DFX_EN=0 不实现控制/端口统计，观测输出全零。开启时所有DFX访问必须管理授权且当前 dfx_authorized_i=1；状态/计数不会因锁关闭。硬件观测组合受授权门控，撤销后不等待寄存器才置零；下一时钟边沿清除未触发武装，优先于同周期武装命令。

目标寄存器写入检查 port/master 范围；武装时复制目标到 armed_port/armed_master 和模式。任一模式已武装时禁止修改目标或再次武装。INJECT_CMD 在屏蔽保留位后恰好一个有效命令位；完整性模式额外要求 PARITY。解除命令可清两种武装，不能撤销已锁存事务结果。自然非法请求不匹配消耗；原本允许的匹配 SETUP 末沿消耗一次。

强制拒绝把结果捕获为0x41，在该事务失败完成边沿记录、计拒绝并触发bit0/bit8。完整性注入在SETUP末沿触发synthetic位置FATAL与完整性候选，在后续LOCAL完成记录0x04且TEST=1；不实际翻转保护位，因此真实故障检查仍由verification注入完成。INJECT_CMD合成日志在其成功完成边沿产生无关联请求的0x40，不计真实拒绝。

## 等待和统计

每笔外设请求锁存wait_count=0及wait_reported=0，仅下游PSEL&&PENABLE&&!PREADY边沿递增。REGISTER_MODE的REG_SETUP不计等待。WAIT_THRESHOLD非零且增加后的计数首次达到阈值时触发一次WAIT_EXCEEDED、设置WAIT_HIT，当前事务继续。阈值寄存器经同一APB口写，不可能在外设等待中被软件改写。

WAIT_TOTAL每个等待周期饱和加一；WAIT_MAX只在完成边沿用本笔wait_count更新，零等待完成值为0。SUCCESS/SLVERR在完成边沿互斥递增，DENY在唯一端口拒绝完成递增。所有计数先清零再累加/取本笔最大值；WAIT_HIT先清后置。wait_count饱和后保持，wait_reported避免重复事件。

busy_o 在有效外设 SETUP/REG_SETUP/ACCESS 可见，active_port_valid 随当前有效外设目标，LOCAL拒绝不表示下游在忙；direct SETUP 取当前组合目标，后续取上下文。active_port无效为零。WAIT_HIT输出是授权门控后的粘滞状态，不是当前等待组合值。审计/irq不受授权撤销影响。
