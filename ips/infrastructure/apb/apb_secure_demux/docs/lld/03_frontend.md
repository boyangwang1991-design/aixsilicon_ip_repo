## 接收状态与请求上下文

顶层状态为 IDLE、LOCAL、REG_SETUP、ACCESS。IDLE 遇 s_psel && !s_penable 的合法 SETUP，在结束边沿锁存完整请求和判定；非唯一外设允许则进入 LOCAL，否则按 REGISTER_MODE 选择 REG_SETUP 或 ACCESS。IDLE 中无先行 SETUP 的 ACCESS 不建立上下文，不产生下游 PSEL，协议检查报告输入违规。

LOCAL 仅在上游 ACCESS 返回完成，完成边沿回 IDLE。REG_SETUP 产生一个下游 SETUP，且强制上游 PREADY=0；一拍后进入 ACCESS。ACCESS 在下游完成前保持，完成边沿回 IDLE。背靠背 APB 在下一 SETUP 周期重新接收，即使 PSEL 一直高也不要求先降零。

上下文包含 PADDR/PWDATA/PSTRB/PWRITE/PPROT、完整 MASTERID 与 valid、port 与 port_valid、csr、reason、policy_version 和 test。所有字段在 SETUP 末沿一次性保存，等待中保持。LOCAL 的 read data 在完成周期来自当前 owner 的只读状态，FIRST/LAST 字0快照保存值与该次返回值相同。

非法 FSM 编码进入隔离状态：无新选择、无本地成功、无状态写；需可信复位恢复。非法状态属于内部硬件故障边界，不能在未知在途上下文下自行制造 APB 完成。

## 输入违反协议

s_psel/payload 在等待期违反稳定性时，断言报告；已发送的事务继续由捕获上下文驱动。无 APB 取消功能，不以 s_psel 下降解释 cancel。正常输入假设在验证环境中明确区分 assumption 与 DUT assertion。
