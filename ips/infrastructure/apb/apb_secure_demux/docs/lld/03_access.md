## 自然判权与优先级

逻辑先给出自然判权，再将 DFX 强制拒绝叠加。主原因严格按 MULTI_HIT、ADDR_MISS、ID_INVALID、INTEGRITY_BLOCK、PORT_DISABLED、INSTR_DENIED、READ_DENIED/WRITE_DENIED 排序。

唯一外设命中时，先用完整 MASTERID 检查 valid 和 <NUM_MASTERS，再读取 active_perm[port][master]。无效身份不读取或映射主体0。类别索引为 {PPROT[1],PPROT[0]}，写操作加4；PPROT[2] 指令写总拒绝，指令读额外要求 INSTR_ALLOW，再查对应读位。PSTRB=0 仍按写检查。MGMT_MASTER_MASK 不参与外设准入。

INTEGRITY_BLOCK 使用 fatal_q || raw_integrity_error；因此稳定原始校验错误在 FATAL 寄存前已经阻断当前新 SETUP。允许结果在 SETUP 末沿捕获；在途事务不再经过该判断。

DFX 武装匹配必须自然允许、目标身份和端口相同、DFX_EN 及当前授权有效。deny 模式改为 DFX_FORCED_DENY；integrity 模式改为 INTEGRITY_BLOCK 并在 SETUP 边沿产生带 TEST 的完整性候选。未满足自然准入不消耗武装，授权撤销也不触发。锁存结果不受后续授权变化影响。
