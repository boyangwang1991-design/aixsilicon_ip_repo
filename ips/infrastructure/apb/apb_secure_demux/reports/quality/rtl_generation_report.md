# RTL implementation candidate

All nine approved LLD module responsibilities now map to eight handwritten SystemVerilog modules (FRONTEND/ROUTE share the top). Native CSR is regenerated by PeakRDL with a distinct `apb_secure_demux_csr_regblock` module name. RDL-derived instance constants/security regions and external-register wiring live in rtl/instance; no handwritten duplicate offset table.

Six behavioral leaves have executed self-checking tests. Top-level SpyGlass reports zero Fatal/Error; warnings remain subject to classification. The typical direct-mode top integration UT passed 31 APB transactions / 160 checks with assertions enabled after reset initialization. These results do not establish complete Module UT, full configuration coverage, formal properties or G3/G4 signoff.

The initial policy run returned exit 0 and a PASS marker but contained 30 time-zero CBB assertion errors; that run is failed. The CBB excludes X/Z input guarantees, so its checkers are disabled only during DUT reset initialization and enabled before functional stimulus. Retry passed; CBB source is unchanged. Native CBB core metadata lacks paramtype; a local metadata-only adapter is used and remains a dependency packaging gap.

See rtl_leaves for raw run manifests, failed attempts and current evidence. Native CSR scope, full gate status and release status must be assessed separately. No release has been created.
