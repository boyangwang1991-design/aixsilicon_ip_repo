#### Requirement

一个 frame 包含 `FRAME_BITS=1..32` 个串行 bit；一个 TX/RX FIFO entry 对应一帧，固定存储 32 位。有效数据右对齐在 `[FRAME_BITS-1:0]`。TX 高位忽略，RX 高位补零。

#### Acceptance Criteria

- 对照原合同 DAT-001 的全部条件，检查可观察结果及异常路径；不得以成功通路替代边界检查。

#### Requirement

MSB-first 按 `FRAME_BITS-1` 到 0 发送/接收；LSB-first 按 0 到 `FRAME_BITS-1` 发送/接收。回读数据的数值位置与发送定义一致，不因位序选择而自动 byte swap。

#### Acceptance Criteria

- 对照原合同 DAT-002 的全部条件，检查可观察结果及异常路径；不得以成功通路替代边界检查。

#### Requirement

8-bit 帧时一次 TXDATA 写入一字节有效载荷，不把 32 位写数据自动拆成四字节。驱动应使用对齐 32 位 MMIO；多字节协议的字节顺序由 entry 顺序决定。例如地址 `0x123456` 应依协议分别写入 `0x12,0x34,0x56`。

#### Acceptance Criteria

- 对照原合同 DAT-003 的全部条件，检查可观察结果及异常路径；不得以成功通路替代边界检查。
