#### Requirement

多个运行期条件同时出现允许多位置位；每次 APB 访问先检查地址/方向/对齐/strobe，失败仅记 APB_ACCESS；之后检查目标操作，记相应专用错误。非法 ACTION 组合或忙态 ACTION 记 APB_ACCESS。错误 CSR W1C 清除不解除 FAULTED。

#### Acceptance Criteria

- 对照原合同 ERR-001 的全部条件，检查可观察结果及异常路径；不得以成功通路替代边界检查。

#### Requirement

设计应通过资源预留避免真正 RX overflow；不得把覆盖旧数据作为正常流控策略。V1.0 不宣称检测所有内部硬件故障、线上 bit 错误或从机命令执行结果。

#### Acceptance Criteria

- 对照原合同 ERR-002 的全部条件，检查可观察结果及异常路径；不得以成功通路替代边界检查。
