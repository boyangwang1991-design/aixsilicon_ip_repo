# Watchdog：全局周期、编码及实现约束

## 边沿模型与优先级

每个 WDT 上升沿以旧寄存状态 q 计算候选年龄和事件集合，再构造唯一下一状态 n。
寄存器在该边沿采样 n；快照采样同一 n，而 FIRST_FAULT 的原因上下文选取旧配置、旧
状态及本拍候选年龄。组合逻辑先完整默认赋值，禁止锁存器、多驱动和组合时钟。

优先序：POR → 致命异常/最终到期 → 主超时与服务/Deadline 违规 → 可信恢复 → 完整
服务及旧配置成功边界应用 pending → START/STOP → 暂停进退 → 普通计数/预警/清除。
所有同拍原因先 OR 收集，优先序只选择互斥状态动作，不删除低优先级诊断原因。
事件 set 与 W1C 同拍时 set 优先。故障不得被清除、暂停或 STOP 掩盖。

## 数值和接口规则

计时 C/Deadline 为 COUNTER_WIDTH 位无符号饱和数；分频 D 为 PRESCALE_WIDTH 位。
序列年龄/升级年龄/故障统计使用 32 位饱和数，恢复次数 8 位饱和，ALIVE 16 位饱和。
邮箱/配置版本/完整客户端服务序号为 32 位自然回卷；只在其定义的成功事件更新。
表达式先扩宽再加/比较；禁止 signed 整数符号扩展改变期限，禁止截断非法配置后执行。
诊断高低字为 64 位容器，高于实际位宽的读位补零，写入非零高位在提交时拒绝。

APB 仅 ACCESS 完成边沿产生副作用，staging 和选择器归接口复位域；邮箱、完成记录、
保持镜像归 POR 域。外部 WDT 控制输入已同步，hw_evt 使用 valid/ready 保持协议。
PSTRB 只在写时全字检查；PPROT 是协议属性，不替代独立授权侧带。

## 编码与可实现性

通道状态采用 3 位 binary 0..5，6/7 致命；关键状态另加保护副本。操作/result 编码
以输入契约 §16.4 和共享 package 为设计关联，结构及软件派生视图必须核对一致。
所有参数边界沿 PC 合同检查；SAFETY_EN 控制增强保护，DIAG_INJECT_EN 控制入口，
关闭能力的访问返回明确错误或规范零值，不能静默模拟成功。

同步寄存器标注 async_reg；稳定负载的数据路径独立 max_delay/稳定窗口约束，不能
靠整域 false-path 宣称 CDC 正确。冗余寄存器和不同比较锥保持综合独立性。
RTL 中断言采用独立 bind/验证文件；生成 CSR 的条件断言按 SYNTHESIS 预处理核验。
