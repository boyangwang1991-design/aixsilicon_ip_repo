# Watchdog：RTL 映射与实现交付

本表定义逻辑责任到物理RTL的实现意图；现有文件仅为候选，必须按当前LLD核对并修复。
共享watchdog_pkg提供配置/命令/快照类型及确定性算法。CBB以depend引用，不复制源码。
命名逻辑区可以共享文件，但每个设计对象有明确实现owner；安全区域要保持独立状态锥。
