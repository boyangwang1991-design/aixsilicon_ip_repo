每个通道独立 state_t q/n、NUM_CLIENTS 个客户端状态，C/D、配置、锁、服务序列、
故障升级与诊断具有明确下一状态。所有客户端同拍并行评价；不按客户端轮询计时。
cfg_active/cfg_pending 是完整逻辑对象，版本与其一起更新。每拍产生 result 与
snapshot_next，命令可能失败但本拍时间和真实故障仍推进。

保持主状态与事件留痕分离：active_fault/local/final 只按可信恢复/POR 解除，raw
可按 W1C 清除；FIRST_FAULT 无 valid 时仅在新故障进入时捕获。详细状态/服务/
客户端/配置/升级分别分册，不用组合赋值先后顺序隐式决定功能优先级。
