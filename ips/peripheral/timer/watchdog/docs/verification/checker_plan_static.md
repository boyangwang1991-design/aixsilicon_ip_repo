# 静态、故障与性能证明

PC中verify.formal=true的配置必须运行形式检查，计划证明计数有界到期、最终保持和邮箱至多一次。以冻结参数/时钟复位假设约束环境，保存每条property的证明/反例/不可判定结果及深度；不可判定不是PASS。其他动态场景使用仿真断言，不能声称穷尽状态空间。
六条CDC与三类reset来自LLD；SpyGlass CDC/RDC检查同步级、源稳定/目的采样、复位关系和多比特握手约束。
异步stress覆盖源快/目的快、近频、停钟、每一级复位相位；动态通过不替代静态亚稳态分析。
任何waiver必须定位路径、类别、协议证明及约束，不能全局忽略同步后宽总线。

性能：启动/刷新边沿为计时起点；稳定时钟下无竞争WDT可见后≤2边沿，有连续硬件竞争≤3；APB ACCESS≤2pclk。
测量窗口先完成POR及已知命令基线，再运行至少100次事务，分别记录最大延迟和分布；停钟场景不混入有界指标。
故障延迟以注入真正激活的边沿起算，观察safety_alert/system_reset_req，不能用软件写INJECT的APB边沿替代。

安全故障模型列出受保护寄存器、比较路径和final独立保持；六种入口加bind单点扰动，正常/暂停/饱和/服务/恢复均检查。
真实28nm综合约束保护冗余路径；综合网表核对主/影子计数、比较锥和final hold触发器存在且未合并。
数字注入不能证明模拟、全时钟停振、失电和共因覆盖；安全手册逐项列明。
