# Watchdog：L1 模块划分

六个模块是架构责任边界，既有候选 RTL 的组织不构成冻结要求。

```mermaid
flowchart LR
  SW[软件/APB] --> BUS[BUS 接口/staging/镜像]
  BUS --> TR[TRANSPORT 命令/完成/错误]
  TR --> DP[DISPATCH 仲裁/路由]
  HW[同域硬件事件] --> DP
  DP --> CH[CHANNEL 独立监督状态]
  CH --> TR
  CH --> SF[SAFETY 独立检测]
  SF --> CH
  CH --> INT[INTEGRATION 请求汇总/系统边界]
  SF --> INT
  INT --> SYS[可信系统管理器]
```
