软件先查询在途状态，再提交完整字命令。BUS 完成权限/格式检查并一次性捕获身份、选择器、
负载与配置快照；TRANSPORT 在空闲时接收并保留身份。目的域可见后 DISPATCH 与硬件
事件公平仲裁，CHANNEL 按执行边沿的状态、窗口和权限产生结果；完成/取消结果连同
序号经 TRANSPORT 返回，BUS 发布 DONE 记录。APB 接收成功不是 WDT 执行成功。
忙拒绝不排队、不覆盖；软件等待超时先查询最终结果，不能无条件重发。

每通道及每客户端 staging 独立保存。提交捕获完整配置，CHANNEL 校验全体适用字段，
失败整体拒绝。禁用态可立即激活；运行更新只允许规定的计时字段，且旧配置定义的
成功刷新边界才整体切换；ALIVE 只在健康周期边界切换。pending 期间第二次提交拒绝，
故障/warm/取消清理未生效更新但保留活动配置，版本可有取消造成的间隙。

CHANNEL 独立推进主计时；完整服务经过路径/来源/状态/算法/客户端/时间窗校验才贡献
健康条件。SINGLE 成功直接刷新，GROUP 最后一个必需客户端完成才刷新，ALIVE 在
固定周期边界评价计数，FLOW 要求线性检查点与独立 Deadline。第一次密钥及其他
不完整操作不得改变主期限；主 TIMEOUT/Deadline 到期优先于同拍完整服务。
TOKEN/QA 使用确定性种子和更新算法，成功客户端完成才更新；重复 GROUP 报到不
更新 token。BOOT 使用独立首轮期限，首次完整健康周期后转普通运行，重复 START
不再授予宽限。
