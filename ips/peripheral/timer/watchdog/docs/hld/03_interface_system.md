# Watchdog：外部接口合同

所有可信输入均有明确系统来源，异步信号在进入本合同前同步或完整握手。

recovery_done_i/recovery_ack_o 均逐通道；只有合格局部恢复完成才可接受。双方回零后重新武装，旧 done 电平不授予新的恢复。
