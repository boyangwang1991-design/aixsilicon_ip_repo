# GPIO DFX 与约束

IRQ_TEST、DIAG_TEST 和 PARITY_INJECT 分别检查不同的记录/报警/安全路径，不能混用来证明PAD路径。Strap早请求被忽略并记故障；软件须重试。没有新增scan/JTAG/MBIST接口要求。

## BALANCED

IRQ汇总与Bank读回必须分层平衡，避免128路非必要串行链；事件仲裁选择最小pin_id。
