# GPIO 高层数据流

```mermaid
flowchart LR
 APB[APB检查] --> REG[CSR与命令分发]
 PAD[PAD输入] --> IN[输入处理]
 IN --> IRQ[中断与边沿]
 IRQ --> FIFO[事件FIFO与时间戳]
 REG --> OUT[输出与覆盖]
 OUT --> GATE[能力与拥有权门控]
 REG --> MB[跨域命令]
 MB <--> AON[AON唤醒]
 IN --> CAP[快照与Strap]
 IN --> DIAG[诊断与parity]
 DIAG --> OUT
```

## 输入到中断与捕获

输入物理值先经过同步、有效性/滤波/去抖资格，再生成逻辑数据。IRQ使用有效逻辑值检测；Strap与诊断使用物理同步视图。
