#### Responsibility

命令生命周期、唯一 descriptor shadow、completion 发布和 BUSY 锁定。
组合语义校验委托 FE.VALIDATE；在接受 doorbell 时锁存能力使能和算法掩码。
validated command 仅在 EXECUTE/COMMIT 且无清除、取消、锁定或故障时有效，其余时间全零；
该视图复用 shadow，不另存一份 descriptor。
固定长度总线抓取委托 DESC_FETCH；寄存器存储/字段更新由生成 CSR 承担，APB adapter
承担总线转换。FE 仅输出状态和更新事件，不能重复实现寄存器存储或 APB 协议。

控制状态用 16-bit one-hot，未使用编码也非法；一个 bit 翻转不能从任一合法状态
进入另一个合法状态。FAULT 检查完整向量，不能截成当前 RTL 的旧 10-bit 接口。

DISABLED 等待复位擦除完成和 enable，再进入 SELFTEST；真实自检完成且通过后 IDLE。
门铃只在 IDLE 接受，接受沿锁定完整命令身份/来源安全属性、入口地址和 context。
首先 FETCH 固定 128 B descriptor shadow，完整抓取并验证 AXI 长度/RLAST 后才
VALIDATE；不能先校验尚未加载的 descriptor。校验不读取私钥、不发 payload DMA。

VALIDATE 检查 ABI、CRC、保留位、opcode/pset、精确输入长度、输出容量、context、
地址加法溢出、对齐/重叠、DMA 安全窗口和用途。检查统一完成后才 ACQUIRE 私钥 grant
并进入 EXECUTE；KeyGen/Encaps/Verify 不伪造必须有私钥 handle 的条件。
来源身份由可信 SoC 属性给出，不能用 descriptor 自声明的 owner 代替授权。

EXECUTE 只接受本 command epoch 的算法结果。KeyGen 还要等待 WORKKEY custody
确认，Sign 必须有全部检查完成及接受标记。算法失败进入 ERROR/清除，不开放候选页。

COMMIT_PAYLOAD 锁定获准输出页范围及长度，等全部 AXI B 响应成功；随后
COMMIT_RECORD 写完成记录，再等其 B 响应成功。只有之后 COMPLETE 才更新完成状态
并置 DONE IRQ。任何 B 错误进入 ERROR，既有已接受的公开写不能回滚，软件必须
以完成记录/状态判定成功，不能把缓冲区部分内容当作有效结果。

软件 abort 仅在提交 payload 之前立即接受并清除；已经提交时记录待退休请求，
遵守 HLD 提交边界。fatal/revoke/zeroize 从任意状态优先取消授权并清除，可导致
部分公开输出已写，但绝不发布成功。ERROR 只在完成记录地址本身已被合法校验时
写错误记录；描述符/地址错误不得使用未可信的指针发起错误 DMA。

ZEROIZE 等所有参与者，包括两 share、随机缓存和外部排空完成；内部超时锁定并
保持清除请求，不生成成功完成。非致命、已完整退休的取消才允许回到 IDLE。

## 实现映射

descriptor shadow 是本模块内部 buffer，使用 LLD.BUF.PQC.FE.DESC；寄存器行为
来自 register_behavior 分册，生成 CSR 经 APB adapter 接入。原先 FE.DESC/FE.REG
只是概念名，未定义为真实子模块，不能出现在 RTL_MAP 的 implements 清单中。
真实抓取子模块现在定义为 `LLD.MOD.PQC.FE.DESC_FETCH`，接口/FSM/实现差距见
[`03_fe_desc.md`](03_fe_desc.md)；它的 beat hold 不替代 FE 的完整 shadow。

## 描述符接受边界的过渡实现

门铃只接受上升沿；持续为高的请求不会在返回 IDLE 后自动重放。忙时收到的门铃不
排队，APB 包装层拒绝对应写入。接受门铃沿锁存完整 40-bit 描述符地址，抓取与对齐
校验只读该快照；外部 CSR 地址变化不能改变已接受事务。

ML-KEM Decaps 的公开密文使用 SRC0，描述符 0x18..0x1f 为 little-endian 64-bit
长度。三个参数集分别精确要求 768、1088、1568 B；包含高位的任何不等值在原语
启动前返回 ERR_BAD_LENGTH。KEMSEQ 比较上界由锁存参数集的规范长度提供，不能
从实时 CSR 或乘法估算取得。私钥材料仍由 WORKKEY 专用路径授权。

zeroize 同拍禁止新的抓取、算法启动、DONE/IRQ 发布；清除沿同时擦除 128 B shadow、
CRC、地址快照和 completion tag。关闭发布不等同于 DMA 排空或全局清除应答。
