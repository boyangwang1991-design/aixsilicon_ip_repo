# 02 · 必要的数学：从整数到带噪声的多项式

[上一章](01-pqc-basics.md) · [学习首页](../index.md) · [下一章](03-ntt-and-modular.md)

## 模运算就是在固定范围内表示整数

`a mod q` 取除以 q 的非负余数。例如模 17 时，`20=3`、`-1=16`、`15+5=3`。在程序中 `[0,q)` 称为规范 residue（余数）表示。

同一数还可以采用中心表示：模 17 的 16 表示为 -1，更方便判断它是不是“小噪声”。从存储中的 `q-1` 看到一个大正整数，不意味着它对应的数学噪声很大。

若 q 是素数，非零数通常可以“除”：除以 a 是乘以模逆 `a⁻¹`，满足 `a·a⁻¹ mod q=1`。例如模 17 的 `2⁻¹=9`，因为 `2×9=18=1 mod 17`。模除法不能直接用普通整数截断除法替代。

## 一个多项式就是一个系数数组

`a(x)=a₀+a₁x+…+a₂₅₅x²⁵⁵` 在代码中是长度 256 的整数数组。x 是形式符号，芯片不需要给 x 输入一个实数；硬件操作的是系数。

本项目的两个算法都在下面的环中运算：

```text
R_q = Z_q[x] / (x^256 + 1)
```

它有两条规则：系数按 q 取模；次数超过 255 时按 `x²⁵⁶=-1` 折回。这叫负循环卷积。它不同于使用 `x²⁵⁶=1` 的普通循环卷积。

### 可以手算的微型例子

为了练习，把 n 暂时缩成 4，q 取 17。这只是教学例子，不是任何标准参数集。

```text
a(x) = 1 + 2x       → [1,2,0,0]
b(x) = 3 + x³       → [3,0,0,1]
a·b  = 3 + 6x + x³ + 2x⁴
     = 1 + 6x + x³  → [1,6,0,1]，因为 x⁴ = -1
```

对应源码是 [modular.py](../../pqc_accel_model/src/pqc_hw_model/modular.py) 的 `negacyclic_schoolbook`：当 `i+j>=n` 时，向 `out[i+j-n]` **减去** 乘积。它是理解 NTT 乘法正确性的一个慢速参照。

## 向量与矩阵中的每个元素也是多项式

ML-KEM 的 `A` 是 `k×k` 的多项式矩阵，`s` 是 k 个多项式组成的列向量：

```text
t = A·s + e
t[i] = Σ A[i,j]·s[j] + e[i]
```

这里的一个乘法是两个 256 系数多项式相乘，一个加法是 256 个模加。ML-DSA 的 A 是 `k×l`，`s1` 有 l 个多项式，`s2` 和 `t` 有 k 个多项式。不要把 ML-DSA-65 的 6 行、5 列颠倒。

## 噪声为何重要

若公开 `A` 和 `t=A·s`，线性代数可能帮助恢复 s。加入受控的小噪声 `e` 后，问题变成从带误差的关系恢复秘密。这里的直觉是“很多维度上的模运算带噪声方程”，不是“随意加噪声就安全”；噪声分布、维度、模数都由算法精确规定。

一个模 17 的标量玩具例子是 `t=5s+e mod 17`：给定 t=9，`s=2,e=-1` 可以成立。这个小例子容易枚举，没有密码安全性，只用于说明误差让等式不再是简单的无噪声反解。

ML-KEM 用噪声遮蔽秘密并设计可恢复的消息区间；ML-DSA 用短向量关系与随机候选、挑战、拒绝机制构造签名。两者共享运算结构，安全推理和使用方法并不相同。

## 范数与“足够小”

无穷范数 `||v||∞` 是所有系数取中心表示后，绝对值的最大值。例如 `[1,-3,2]` 的无穷范数是 3。签名中常见要求 `||z||∞ < bound`，等于 bound 也应拒绝。

硬件无需真的求最大值再比较；可以对所有系数比较，并把失败位做 OR 累积。全部遍历后再作决定，也有利于避免通过提前停止位置泄露信息。

## 数学对象与存储对象

| 对象 | 数学视角 | 工程视角 |
|---|---|---|
| 一个系数 | 模 q 的整数 | 普通余数、中心数或带缩放表示 |
| 一个多项式 | 环元素 | 256 个系数及表示标签 |
| NTT 结果 | 同一运算问题的变换表示 | 另一个数组排列和运算规则 |
| 编码公钥 | 数学对象的序列化 | 位紧凑的字节串 |
| 矩阵种子 | 确定性展开的输入 | 几十字节种子，节省矩阵存储 |

硬件工作页按 256×32 bit=1024 B 预算，不代表外部每个多项式都占 1024 B。例如 256 个 12-bit 系数紧凑编码只占 384 B。

## 检查理解

1. 模 3329 中 -2 的规范表示是多少？**3327。**
2. 在本项目的环里，`x²⁵⁵·x` 是多少？**-1，即常数系数 q-1，其余为零。**
3. 32-bit SRAM word 是否说明 q 有 32 bit？**不是，这是物理存储宽度。**
