# 后续设计决策授权

用户原文：“后面又需要决策的，按照你推荐的来”。

适用于当前 PQC 修复与 ip-development-suite 完整交付任务中的后续设计决策。
Agent 应直接选择推荐方案，记录依据、影响及验证义务，不重复请求相同范围的决策。
执行必要技术评审后，可按 user_delegated 方式记录阶段冻结，绑定当时输入指纹；
不得冒称独立人类评审，不得仅凭本授权把未完成的设计或验证标记为通过。

已确认的约束继续生效：内部工作态 Key RAM、外部长期 Key Manager、专用私钥
导入且默认不可读回；PPA 采用代码结构分析；保留 1/2 轮结构，按安全等级制定
可达周期预算；Sign 单次尝试固定调度、总时延可变；Level 2 实现与验证本轮必交。

当前推荐方案为两 share，全敏感链路保持掩码；布尔非线性采用 HPC3+ 候选，
算术/布尔转换与组合验证独立闭环。随机数、存储和延迟代价均显式计入预算。
方案如因实际证明/实现失败需要调整，重新打开受影响阶段并重建证据，不隐去失败。
